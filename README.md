# Abschlag-Trainer

Eine kleine Golf-Web-App. Sie läuft komplett im Browser und lässt sich als App auf dem Handy installieren (PWA).

## Starten

- `index.html` direkt im Browser öffnen, oder
- über GitHub Pages veröffentlichen: Settings → Pages → Branch `main` → Ordner `/ (root)`.

Auf dem Handy die Seite öffnen und „Zum Home-Bildschirm hinzufügen“ wählen.
